10. TROUBLESHOOTING QUICK REFERENCE
================================================================================

Sitemap not updating?
  → Rank Math updates on post publish (usually within 1 hour)
  → Manual: WordPress Admin → Settings > Rank Math > Regenerate Sitemap

Posts not indexing?
  → Check: robots.txt allows the path
  → Check: Post settings have no "noindex" tag
  → Submit: URL directly in Google Search Console
  → Wait: 24-48 hours for Google's crawler

Robots.txt issues?
  → Current: https://21degrees.in/robots.txt (200 OK)
  → Backup: https://21degrees.in/wp-content/uploads/2026/11/robots.txt
  → Content: Properly formatted with sitemap references

Indexing slow?
  → Check: Google Search Console for crawl budget
  → Check: No robots errors or "not crawlable"
  → Verify: Sitemap has recent update date
  → Rank Math: May need to resubmit in search consoles
